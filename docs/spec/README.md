## 記述の規律

1. **実装が出典** — 数値・スキーマ・条件は `file:line` を明記する。コードにない保証は書かない。
2. **未決は未決と書く** — ADR で開いたままの論点（λ の scenario 側較正、シナリオ数 S）を確定事項として書かない。
3. **単位を必ず添える** — wei / units（6 decimals）/ bps / USDC / ブロック / 秒。
4. **識別子は原文のまま** — ファイル名・型名・イベント名・config キー・アクション名は英語のまま書く。

## 更新するとき

実装を変えたら、その章の該当節と `file:line` を同じコミットで直す。出典行がずれただけの更新でも直す — 追跡できない出典は出典ではない。
