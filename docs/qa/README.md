# Q&A

参加者からよくある質問への答えを、規約と対象の一覧から書いたものです。ダッシュボードの「Q&A」が、ここのファイルをジャンルごとに並べて表示します。

正本は [ascon.dev](https://ascon.dev) の各ページです。ここと食い違ったらそちらが優先します。

## 書き方

- 1 項目 1 ファイル。`<番号>-<名前>.md` が日本語、`<番号>-<名前>.en.md` が英語。同じジャンルの中では番号の順に並びます
- ファイルの先頭に、ジャンルを frontmatter で書きます。`genre` の値は `genres.json` の `key` のどれかです

  ```
  ---
  genre: scope
  ---
  # 項目の題名
  ```

- `#` は項目の題名（GitHub で読む人のため。ダッシュボードでは出ません）、`##` が質問です。質問の見出しはアンカーになるので、Q&A 全体で重複しないようにします
- ジャンルを増やすときは `genres.json` に `{ "key", "ja", "en" }` を足します。並び順はそのファイルの順です。項目の無いジャンルは表示されません
- 使える記法は更新履歴と同じ（見出し・段落・太字・コード・リンク・表・箇条書き・コードブロック）。`npm test` の `dashboardMarkdown` が描画を検査します
