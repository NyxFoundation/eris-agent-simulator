# 2026-11-26 Models added, and models you can no longer use

The list of models for strategy revision (inference; rules §2.5 and Appendix A) has been updated. Scoring, prizes and the schedule do not change.

## Added

Under Appendix A ("the organizer may add models the provider newly offers"). They can be used in the live competition.

| Inference service | Models |
|---|---|
| Anthropic API | `claude-fable-5-2` |
| OpenAI API | `gpt-6.2-astra`, `gpt-6.2-sol`, `gpt-6.1-terra` |
| Ollama Cloud | `kimi-k3.1-pro` |

To use one, name it as `model` in your submission's `prompt.md` and submit that service's API key through the key registration form. Both by the end of the submission period (**Nov 30, 24:00 JST**).

## Removed (no longer usable)

| Inference service | Models | Why |
|---|---|---|
| Ollama Cloud | `minimax-m2.7`, `mistral-large-3` | Ollama retired them on 2026-11-09 (Appendix A: a model its provider stops offering can no longer be used from that point) |
| OpenAI API | `gpt-oss-120b` | OpenAI's API does not serve it through Chat Completions, and its rate limit is 0 on every tier, so it cannot be called. For gpt-oss at 120b, name Ollama Cloud's `gpt-oss:120b` |

**If your `prompt.md` names one of these, change it to another model and resubmit by Nov 30, 24:00 JST.** Otherwise its inference calls will be refused during the live competition and your strategy will not be revised (trading continues on the strategy as it was).

## Scheduled retirements

OpenAI retires `gpt-5`, `gpt-5-mini`, `gpt-5-nano`, `gpt-5-pro`, `o3` and `o3-pro` on 2026-12-11. They remain usable through the live competition (Dec 1 – 7, reserve day Dec 8).
