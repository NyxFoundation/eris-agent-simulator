# 2026-10-06 The permissionless lending contract (SimpleLending) is no longer deployed in the official regimes

The permissionless lending contract (SimpleLending) that the Organizer deployed at the start of
each run in the twelve official regimes is no longer deployed there. The practice environment never
had it.

The contract is not among the protocols of Competition Rules §3.1. In a run where its scoring
adapter is not enabled, assets put into it counted as zero at the end of the epoch, while markets
anyone created on it appeared in the registry as `verified: true`. A venue stood open that could be
used but only at a loss.

The only strategies affected are those that use the `lending` actions (`createLendingMarket`,
`lendingSupply` and so on) in local backtests. In the official regimes those actions are rejected,
because there is nothing to send them to.

Runs whose `run.protocols` include `lending` (`config/regimes/agent-markets.yaml`) deploy it as
before, and the reference agents market-launcher, market-taker and trap-launcher run as before.

The MarketRegistry, the listings of the launch regime, the pools of the vuln regime, and the
publication of contracts and pools that participants deploy are unchanged. No state dump needs to be
rebuilt.

The list of targets open to exploitation (https://ascon.dev/en/scope) no longer mentions
SimpleLending either.
