# 環境の更新履歴

[スターターガイド](../competition-start.md)は常に最新の環境を書いています。ここは、すでにガイドを読んだ方が差分だけを追えるように、更新を 1 件 1 ファイルで置いた場所です。新しい順に並べています。

規則そのものは [ascon.dev/rules](https://ascon.dev/rules) が唯一の出典です。ここと食い違ったら規約が優先します。

ダッシュボードの「更新履歴」からも同じ内容を読めます。

| 日付 | 内容 |
|---|---|
| [2026-10-08](2026-10-08.md) | priority fee の上限（5 gwei）の撤廃。参照価格はコントラクトへの直接書き込みに変更 |
| [2026-10-06](2026-10-06.md) | 公式レジームの競技環境から許可不要レンディング（SimpleLending）を外した。手元の backtest で `lending` 系の action を使う戦略だけに影響 |
| [2026-10-05](2026-10-05.md) | 練習環境の再構築。練習順位のリセット、全 venue のアドレス変更、コードが動かなくなる 4 件、GMX の手数料と清算、Aave の無料担保について |

英語版は同じ名前に `.en` を付けたファイルです。日本語が正文です。

新しい更新を足すときは、`docs/updates/<YYYY-MM-DD>.md` と `<YYYY-MM-DD>.en.md` を作り、上の表に 1 行足します。ダッシュボードはこのディレクトリを読むので、ページ側の変更は要りません。
