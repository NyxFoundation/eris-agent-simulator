# 2026-11-26 対応モデルの追加と、使えなくなったモデル

戦略の改訂（推論）に使える対応モデルの一覧（競技規約 §2.5・付録 A）を更新しました。評価の方法、賞金、日程は変わりません。

## 追加したモデル

付録 A の「提供元が新たに提供するモデルを一覧に加えることがあり」によるものです。ライブ競技で使えます。

| 推論サービス | モデル |
|---|---|
| Anthropic API | `claude-fable-5-2` |
| OpenAI API | `gpt-6.2-astra`、`gpt-6.2-sol`、`gpt-6.1-terra` |
| Ollama Cloud | `kimi-k3.1-pro` |

使う場合は、提出物の `prompt.md` の `model` にこの名前を書き、そのサービスの API キーをキー登録フォームから提出してください。どちらも提出期間の終了（**11/30 24:00 JST**）までです。

## 一覧から外したモデル（使えなくなりました）

| 推論サービス | モデル | 理由 |
|---|---|---|
| Ollama Cloud | `minimax-m2.7`、`mistral-large-3` | Ollama が 2026-11-09 に提供を終了しました（付録 A「提供元が提供を終了したモデルは、その時点で使えなくなります」） |
| OpenAI API | `gpt-oss-120b` | OpenAI の API では Chat Completions に対応しておらず、利用上限もすべての料金プランで 0 のため、呼び出せません。gpt-oss の 120b を使う場合は、Ollama Cloud の `gpt-oss:120b` を指定してください |

**これらを `prompt.md` の `model` に指定している場合は、11/30 24:00 JST までに別のモデルに変えて、提出し直してください。** そのままだとライブ競技で推論が断られ、戦略の改訂が行われません（取引は改訂前の戦略のまま続きます）。

## 提供の終了が決まっているモデル

OpenAI の `gpt-5`、`gpt-5-mini`、`gpt-5-nano`、`gpt-5-pro`、`o3`、`o3-pro` は、OpenAI が 2026-12-11 に提供を終えます。ライブ競技（12/1〜12/7、予備日 12/8）の間は使えます。
