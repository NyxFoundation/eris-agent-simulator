# 2026-10-29 参照価格の動き方の変更と、参照ランタイムの修正

## 参照価格の動き方を変えます

競技規約 §3.2 を改定し、参照価格と価格のギャップの動き方を変えます。改定版は 10/29 に公表し、11/13 に効力を生じます。ライブ競技（12/1〜12/7）は改定後の規約で行います。試行環境は、これに先立って 10/28 から順に切り替えています。

これまでの設定では、すでに観測した値動きから、その後の値動きの向きをある程度予測できました。今回の変更は、その余地をなくすためのものです。評価の方法、賞金、日程は変わりません。正本は [ascon.dev/rules](https://ascon.dev/rules) の §3.2・§2.7 です。

## ライブ競技で変わること（競技規約 §3.2）

- 参照価格は、エポック開始時の水準へ戻る性質を持たなくなります。1 ブロックあたりの値動きの大きさは変わりません
- 価格のギャップは戻らず、エポックの終わりまで残ります。これまではギャップの 40〜100% が戻っていました。ギャップの向きは次のとおりです
  - 貸借インシデント・CDP インシデント: 下向き
  - スパイク: 上向きに 1 回
  - クラッシュ: 1 回ごとに、上向きか下向きかが半々の確率で決まります
- CEX ドリフトでは、参照価格が一方向に動き続けるのではなく、値動きが一時的に大きくなります。向きは決まっていません
- 清算される側の借り手（Aave と Liquity の victim）を、すべてのレジームで開始前に置きます。借り手がいることは、レジームの手がかりになりません

各レジームの数値は[スターターガイド](../competition-start.md#12-のレジーム)の表にあります。

## 試行環境で変わること

試行環境は止めずに切り替えます。チェーン、残高、建玉、練習用の順位はそのまま引き継ぎます。`manifest.json` を取り直す必要はありません。

- **10/28 から**: 参照価格は、開始時の水準へ戻らない動きになっています。試行環境は 1 か月続く 1 つのチェーンなので、1 ブロックあたりの値動きは本番の約 11 分の 1 にしています。そのため、1 日の値動きの幅は本番の 1 エポックと同じくらいです（競技規約 §2.7 に、この違いがあり得ることを明記しています）
- **11/2 頃から**: ギャップが戻らなくなり、向きは上下半々になります。ギャップの大きさは 2〜4% です。CEX ドリフトの回は、本番と同じく値動きが大きくなる形になります。切り替わりはチェーンのブロック番号で決まるので、日時はチェーンの進み方によって前後します

## 参照ランタイムの修正

`obs.competition.maxCompetitorPriorityFeeWei`（直近のブロックで他者が付けた最大の優先手数料）に、GMX の keeper など、入札競争と関係のない環境の呼び出しが含まれていました。参照ランタイムの `adaptive-arb` / `max-profit-arb` はこの値を上回るように入札するため、必要な額のおよそ 2 倍を払っていました。これを除くように直しました。`maxBlockPriorityFeeWei` も同じです。

- 提出用の ZIP を作り直すと反映されます（`npm run bundle:agent <id>`）
- 試行環境に自分のマシンから参加している場合は、最新の main を取得してエージェントを再起動してください

## お願い

公開セットの結果は、変更の前と後で比べられません。同じシードでも価格の動きが変わります。最新の main を取得して、検証し直してください。

次のような前提で作った戦略は、見直しをおすすめします。

- 価格がエポック開始時の水準に戻る
- 急な値動きの後に価格が戻る
- victim の有無でレジームを見分ける
- CEX ドリフトで価格が一方向に動き続ける

質問は Discord の #ascon で受け付けます。
