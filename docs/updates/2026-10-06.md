# 2026-10-06 公式レジームの競技環境から許可不要レンディング（SimpleLending）を外しました

公式 12 レジームの競技環境で、run の開始時に主催者が配置していた許可不要の貸出コントラクト（SimpleLending）を、配置しないようにしました。練習環境にはもともと配置されていません。

このコントラクトは競技規約 §3.1 のプロトコルに含まれていません。採点アダプタが有効でない run では、預けた資産はエポック終了時に 0 として数えられ、一方で誰かが作った市場は登録簿に `verified: true` で載っていました。使えるのに使うと損をする venue が置かれている状態でした。

影響があるのは、手元の backtest で `lending` 系の action（`createLendingMarket`、`lendingSupply` など）を使う戦略だけです。公式レジームでは、これらの action は配置先が無いため拒否されます。

`run.protocols` に `lending` を含む run（`config/regimes/agent-markets.yaml`）では従来どおり配置され、参照エージェント（market-launcher / market-taker / trap-launcher）も従来どおり動きます。

MarketRegistry、launch レジームの上場、vuln レジームのプール、参加者が配置したコントラクトやプールの公開は変わりません。state dump の焼き直しも不要です。

弱点を突く行為が認められる対象の一覧（https://ascon.dev/scope）からも、SimpleLending の記述を削除しました。
